# Fuentes de referencia del modelo 2.4

Fuentes copiadas antes de incorporar infiltración fluvial en 2.5. Permiten reproducir el JSON 2.4 aportado por el jugador y mantener un control sin transferencia fluvial para la sensibilidad. No contienen otra copia de su partida.

Las recuperaciones 2.4 no se convierten silenciosamente a 2.5: cambia el resultado hidrológico, aunque se conserva la secuencia del PRNG. La aplicación mantiene la copia incompatible disponible para descargar. Los tests comparan clima/PRNG, conservación y recuperación de la versión correspondiente.
